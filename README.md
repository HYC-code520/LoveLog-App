# 💌 LoveLog – Where Memories Live

**LoveLog** is a mobile journaling app for couples and close friends to capture meaningful moments—from spontaneous dates to everyday joys.

Built with **React Native** and **Flask**, it helps users:

- 📝 Log events with photos, notes, emojis, and locations  
- 📆 View memories in a calendar format  
- 🗺️ See events on an interactive map  
- 🎡 Use a decision wheel to help settle “what should we eat?” debates  
- 🧸 Choose personalized avatars and log in securely

---

## 🗺️ Map View

See all your logged memories by location. (Fun fact: some people repurpose this as a “public bathroom finder” 😆)

## 📆 Calendar View

Scroll through your shared journey, filled with past memories and milestones.

## 🎡 Decision Wheel

Can’t decide where to eat? Let the wheel do the work and keep the peace.
